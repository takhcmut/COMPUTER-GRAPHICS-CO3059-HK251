## Repository Structure

The contents are organized into the following main directories:

* **`Slides`**: Contains lecture slides and theoretical materials.
* **`References`**: Additional reading resources, documentation, and useful links.
* **`Exercises`**: Solutions and problem sets for theoretical and practical exercises.
* **`Lab`**: Source code and reports for laboratory assignments.
* **`Assignment`**: Files related to the assignment project.
* **`Final`**: Documents related to the final exam.
